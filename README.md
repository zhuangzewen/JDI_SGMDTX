# 三国谋定天下 - 游戏系统开发文档 (v1.0)

## 项目概述

这是一个基于《三国谋定天下》游戏机制开发的回合制战斗模拟系统。系统实现了武将收集、阵容编排、多局战斗、血量继承等核心玩法。

**当前版本**: v1.0  
**创建日期**: 2026-03-28  
**开发语言**: Python 3.13.2

## 核心模块

### 1. 武将系统 (Hero)

**文件**: `core/hero.py`

#### 类属性
| 属性 | 类型 | 说明 |
|------|------|------|
| `name` | str | 武将名称 |
| `hp` | int | 当前兵力（初始 10000） |
| `max_hp` | int | 最大兵力（随局数变化） |
| `alive` | property | 存活状态（只读，HP > 0 则存活） |

#### 武将数据结构 (heroinfo.json)
```json
{
  "name": "诸葛亮",
  "name_color": "gold",
  "S2": false,
  "S3": false,
  "EX": false,
  "SP": false,
  "faction": "蜀",
  "troop_type": "弓",
  "stats": {
    "strength": 74,
    "intelligence": 260,
    "leadership": 215,
    "initiative": 131
  },
  "self_skill": "草船借箭",
  "bond_list": ["才堪相配", "西蜀之智", "国之栋梁", "薪火相传", "诸葛望族"]
}
```

**属性说明**:
- `name_color`: 名字颜色标识（gold/golden=金色，blue=蓝色）
- `S2/S3/EX/SP`: 武将稀有度标识（赛季武将/EX 武将/SP 武将）
- `faction`: 所属势力（蜀/魏/群/吴）
- `troop_type`: 兵种类型（弓/盾/枪/骑）
- `stats`: 四项基本属性
  - `strength`: 武力
  - `intelligence`: 智力
  - `leadership`: 统帅
  - `initiative`: 先攻
- `self_skill`: 自带战法名称
- `bond_list`: 缘分关系列表

**当前武将池**: 诸葛亮、刘表、陈琳、糜竺、王朗

### 4. 队伍系统 (Team)

**文件**: `core/team.py`

#### 类属性
| 属性 | 类型 | 说明 |
|------|------|------|
| `name` | str | 队伍名称（"我方" / "敌方"） |
| `heroes` | list | 武将列表 |
| `attack_order` | list | 攻击顺序列表 |

#### 类方法
| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `add_random_heroes` | `hero_pool`, `count=3` | None | 从武将池中随机添加指定数量的武将（不重复） |
| `set_attack_order` | None | list | 设置攻击顺序（按照存活武将列表） |
| `get_attack_order` | None | list | 获取当前攻击顺序 |
| `is_alive` | None | bool | 检查队伍是否还有存活的武将 |
| `get_alive_heroes` | None | list | 获取所有存活的武将列表 |
| `attack` | `enemy_team` | list | 所有存活武将按照攻击顺序攻击敌方队伍，返回战斗记录 |

#### 攻击顺序规则
- **第一回合**：按照布阵阶段确定的顺序（武将列表顺序）
- **第二回合起**：按照先攻概率算法重新排序（两队交叉排序）
  - 使用两队交叉排序算法，从两队中各取先攻最高者进行比较
  - 胜者优先进入攻击顺序
  - 先攻比较规则：
    - 先攻差值超过 70 点时，先攻高者必定先手
    - 否则先攻越高，概率越高先出手（使用平方根曲线）

### 5. 战斗系统 (Battle)

**文件**: `core/battle.py`

#### 类属性
| 属性 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| `team1` | Team | 我方队伍 | None |
| `team2` | Team | 敌方队伍 | None |
| `round` | int | 当前回合数 | 0 |
| `max_rounds` | int | 最大回合数 | 8 |

#### 类方法
| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `formation_phase` | None | None | 布阵阶段，确定双方武将的攻击顺序 |
| `start_battle` | None | int | 开始战斗，返回战斗结果（1=我方胜，2=敌方胜，0=平局） |
| `get_remaining_hp` | `team` | int | 获取队伍剩余总血量 |

#### 战斗流程
```
开始战斗
  ↓
布阵阶段
  ├─ 使用两队交叉排序算法确定攻击顺序
  └─ 显示融合后的攻击顺序
  ↓
重置回合数 (round = 0)
  ↓
回合循环 (最多 8 回合)
  ├─ 回合数 +1
  ├─ 所有存活武将按攻击顺序攻击
  ├─ 检查敌方是否全部溃败 → 是 → 结束循环
  ├─ 检查我方是否全部溃败 → 是 → 结束循环
  └─ 继续下一回合
  ↓
战斗结束判定
  ├─ 我方全灭 → 敌方获胜 (返回 2)
  ├─ 敌方全灭 → 我方获胜 (返回 1)
  └─ 回合耗尽 → 平局 (返回 0)
```

### 6. 主程序流程 (main.py)

#### 游戏主流程
```
1. 初始化游戏
   ├─ 创建战场 (Battle)
   ├─ 加载武将池 (heroinfo.json)
   └─ 创建两支队伍 (我方/敌方)

2. 初始阵容确定
   ├─ 从武将池中随机选择 3 名武将（不重复）
   ├─ 显示双方初始阵容
   └─ 固定阵容（后续局数不变）

3. 多局战斗循环 (最多 8 局)
   ├─ 每局战斗
   │  ├─ 布阵阶段
   │  │   ├─ 设置双方攻击顺序
   │  │   └─ 显示双方攻击顺序
   │  ├─ 战斗开始
   │  ├─ 回合制攻击（最多 8 回合）
   │  └─ 战斗结束（分出胜负或平局）
   ├─ 胜负判定
   │  ├─ 一方全灭 → 结束整个对战
   │  ├─ 双方全灭 → 结束整个对战（平局）
   │  └─ 平局且有存活武将 → 进入下一局
   └─ 血量继承
      └─ 将剩余血量作为下局的血量上限（仅存活武将）

4. 八局结束结算
   └─ 依据双方剩余总血量判定最终胜负
```

#### 血量继承规则
- 每局结束后，将**存活武将**的剩余血量作为下局的血量上限
- 已溃败武将（HP = 0）不继承血量
- 武将状态在局间保持（不会复活）

## 游戏规则

### 战斗规则
| 规则 | 说明 |
|------|------|
| 初始兵力 | 每个武将初始兵力为 10000 |
| 攻击顺序 | 每回合所有存活武将同时攻击 |
| 伤害范围 | 100-500 随机伤害 |
| 最大回合 | 每局最多进行 8 个回合 |
| 胜利条件 | 一方全部武将溃败（HP = 0） |

### 多局规则
| 规则 | 说明 |
|------|------|
| 最大局数 | 最多 8 局 |
| 平局处理 | 若 8 回合后未分出胜负，进入下一局 |
| 血量继承 | 下局开始时，存活武将血量 = 上局剩余血量 |
| 固定阵容 | 阵容在第一局确定后不再更换 |
| 最终结算 | 八局结束后，依据剩余总血量判定胜负 |

### 胜负判定
| 情况 | 判定 |
|------|------|
| 局内胜利 | 一方全部武将溃败，立即结束该局 |
| 最终胜利 | 八局结束后，剩余总血量高的一方获胜 |
| 平局判定 | 剩余总血量相同时，判定为平局 |

### 6. 算法系统 (Algo)

**文件**: `core/algo/algo.py`

#### 核心算法
| 函数 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `compare_initiative` | `hero1`, `hero2` | int | 比较两个武将的先攻顺序，返回 1 或 2 |
| `sort_by_initiative_probabilistic` | `heroes` | list | 按照先攻概率对武将列表排序 |
| `merge_sort_two_teams` | `team1_heroes`, `team2_heroes` | list | 两队交叉排序，返回合并后的攻击顺序 |

#### 两队交叉排序方法
1. 将两队武将按先攻降序排列
2. 从两队中各取先攻最高的武将进行比较
3. 胜者进入攻击顺序
4. 重复步骤 2-3，直到所有武将都排序完成

#### 先攻比较规则
1. **绝对优势**：先攻差值超过 70 点时，先攻高者必定先手
2. **概率优势**：差值在 70 点以内时，按差值计算概率（使用平方根曲线）
   - 概率公式：高者先手概率 = 0.5 + √(差值 / 70) × 0.5
   - 曲线特点：差值较小时变化快，接近 70 时变化慢
   - 示例：
     - 差值 0：50% 概率
     - 差值 5：63.4% 概率
     - 差值 10：68.9% 概率
     - 差值 20：76.7% 概率
     - 差值 35：85.4% 概率
     - 差值 50：92.3% 概率
     - 差值 70：100% 概率
   - **概率只与差值有关，与基础值无关**

## 注意事项

1. **武将存活判定**: 武将血量大于 0 才能攻击
2. **血量继承**: 只有存活武将才能继承血量进入下一局
3. **固定阵容**: 阵容在第一局确定后不再更换
4. **随机性**: 伤害值和攻击目标均为随机，每次运行结果可能不同
5. **数据文件**: 修改 JSON 文件后需要重新运行程序才能生效
